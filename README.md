# CareConnect

## Objetivo

CareConnect es una plataforma que conecta familias con cuidadores de confianza. Facilita la búsqueda, contratación y coordinación de cuidados de personas mayores, niños o personas que necesitan asistencia.

El proyecto demuestra una arquitectura moderna con funcionalidades avanzadas de geolocalización, comunicación en tiempo real y gestión de disponibilidad.

## Arquitectura
- **frontend/** — Interfaz de usuario (React + Vite)
- **backend/** — Servidor de aplicaciones (NestJS + PostgreSQL)

## Características Principales

### Para Familias
- **Búsqueda por ubicación** — Encuentra cuidadores cerca de vos usando el mapa interactivo
- **Filtros avanzados** — Filtra por tipo de cuidado, disponibilidad, tarifa y valoraciones
- **Chat en tiempo real** — Comunicate directamente con los cuidadores antes de contratar

### Para Cuidadores
- **Perfil profesional** — Muestra tu experiencia, certificaciones y disponibilidad
- **Calendario inteligente** — Define tu horario y dias disponibles
- **Geolocalización** — Indica tu zona de cobertura para aparecer en búsquedas relevantes

### Seguridad y Confianza
- **Control de acceso** — Diferentes permisos según el tipo de usuario (familia o cuidador)
- **Protección de datos** — Cumplimiento con buenas prácticas de seguridad de la información

### Experiencia de Usuario
- **Diseño moderno y accesible** — Interfaz limpia adaptada a todo tipo de usuarios
- **Rendimiento optimizado** — Carga rápida y respuesta inmediata
- **Funciona en cualquier dispositivo** — Desde celulares hasta computadoras

### Tecnología y Calidad
- **Código probado** — Tests automatizados que garantizan el correcto funcionamiento
- **Procesos en segundo plano** — Notificaciones y tareas pesadas no bloquean la aplicación
- **Documentación interactiva** — API documentada y fácil de explorar para desarrolladores

### Infraestructura
- **Contenedores Docker** — Despliegue sencillo y consistente en cualquier entorno
- **Base de datos relacional** — Almacenamiento estructurado y eficiente de toda la información
- **Escalable** — Preparado para crecer según la demanda
